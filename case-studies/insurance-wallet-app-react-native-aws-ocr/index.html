Insurance Wallet App: React Native, ID Scan OCR and an AWS Backend

A React Native insurance app where one account replaces many policies: open it by photographing an ID, choose covers, and claim with photos, on a Cognito, Lambda and DynamoDB backend. Client contract, 2018 to 2019.

react nativeaws lambdacognitodynamodbgoogle visionocr

The problem

People held separate policies for family, car, travel and home, each with its own sign-up and its own claim form. The client wanted one app where an account opens in a minute and a claim starts from a photo.

What I built

  • Open an account from an ID photo. The app sends the licence photo to a Lambda, Google Vision reads it, and the name, ID number and dates are parsed out of the text and shown back for the user to approve.
  • Phone login with no password. Cognito with custom auth challenge Lambdas sends and checks a one-time code.
  • Covers and preferences. Family, mobility and property cover, with travel preferences such as winter sport or flight cancellation feeding a cover calculation.
  • Claims with photos. The user says whose property was damaged and who was responsible, uploads photos to S3, and gets recommended repair places on a map.
  • Mobility data. A native module streams location history and driving state from a mobility SDK to the API; a scheduled Lambda writes daily summaries to DynamoDB.

Stack

React Native 0.55, Redux, React Navigation, AWS Amplify, Cognito, API Gateway, Lambda (Python and Node), DynamoDB, S3, Google Vision
