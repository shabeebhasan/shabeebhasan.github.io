A production Laravel application on AWS, maintained and extended continuously from 2018 to 2021 for the same client — plus a Laravel backend for a doctor-patient mobile app and enterprise PHP with SAP integration.

The Brief

Anyone can start a Laravel project. This engagement was the other kind: take responsibility for a client's production Laravel application on AWS and keep it moving — features, fixes, deployments — for what became three continuous years with the same client.

What I Delivered

  • Three years of production ownership (2018–2021): schema migrations, API endpoints, background jobs, AWS deployments, and the unglamorous discipline of never breaking the live system.
  • A Laravel backend for a doctor-patient mobile app: appointments, roles and permissions, and the REST API the mobile clients ran on.
  • Enterprise PHP with SAP integration for dis-connect.de in Germany (2024–2026) — PHP talking to enterprise systems where correctness is contractual.
