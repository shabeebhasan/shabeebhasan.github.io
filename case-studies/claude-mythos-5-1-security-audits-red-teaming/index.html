What this is

I use Claude Mythos 5.1, Anthropic's gated security model, to attack software the way a skilled adversary would: it plans the strategy, I run it against your system in a sandbox, and every attempt is logged as evidence. Then I fix what breaks. My workspace has Defense Access under Anthropic's Cyber Verification Program, so this is defensive, authorised testing only: your system, your written permission, a copy or test environment.

Most "AI security scans" give you a long list of guesses. This gives you attacks that were actually tried, the ones that worked, the evidence, and the fix.

Real project: red-teaming a continuous authentication system

A security startup built a system that keeps checking, from phone motion sensors, that the person using a session is still its owner, and blocks protected actions when it is not. I built the test harness and ran the adversarial campaign against it.

  • Two environments, identical except the protection. The protected build and an unprotected control, both measured, so the comparison means something.
  • 48-hour adaptive campaign. Model-planned attack strategies, millions of generated signal variations, real protected-action attempts, all with exact counts and hash-chained evidence.
  • Result. Fabricated sensor signals, a different person taking the phone, protocol attacks and enrolment poisoning: zero breaches. The only attacks that passed needed the owner's own captured signal (replay), a limit we had flagged in advance, reported separately and honestly rather than hidden in a single percentage.
  • Live demo on real cloud actions. A $1 Stripe test payment, deleting a Cloud Run service and signing a release with Cloud KMS: blocked 15 of 15 times with governance on, executed 25 times with it off, each with a Stripe payment ID or KMS signature as proof.
  • Mythos 5.1 as the attack planner. The first campaign used Claude Opus 4.8, because Mythos was not yet available to us. It is now: Mythos 5.1 plans the next round of strategies, for example feature-preserving perturbations aimed at the continuity check, recorded with request IDs as proof of the model used.
