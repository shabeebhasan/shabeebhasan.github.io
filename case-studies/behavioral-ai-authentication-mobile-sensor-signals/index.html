Behavioral AI Authentication

An anonymized mobile security system that used sensor signals to detect handoff events, score confidence, and revoke or restore access based on owner behavior.

What It Did

  • Detected live handoff and control changes
  • Separated owner and non-owner confidence
  • Recovered access only when the owner returned

Outcome

The workflow enforced immediate response to unauthorized control and kept recovery behavior consistent under real use.

Scope

Mobile sensor processing, scoring logic, state transitions, and protected-action gating.
