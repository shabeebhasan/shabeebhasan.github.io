# Resume source and positioning

`roles.json` supplies eight targeted resumes. Rebuild with `python3 scripts/build_role_resumes.py`, then `python3 scripts/build_resume_hub.py`. The second script rebuilds the resume hub and aligns home-page positioning; legacy PDF filenames remain supported.

Primary positioning: Forward Deployed AI Engineer, focused on customer-facing AI agents, RAG and integrations. This is target-role positioning, not a claim that past employment carried that title or that all software experience was AI work.

Source facts: `/Users/shabeeb/growth-stack/CONTEXT.md`, `upwork-watcher/PROFILE-HUB.md`, `upwork-watcher/profile/17-project-catalog.md`. Career metrics use the verified local profile baseline rather than a live marketplace query. Own builds, paid prototypes, team contributions and delivered client products must remain explicitly distinguished.

Demand review: 1,278 archived job IDs were rule-categorized; 49 relevant descriptions were individually reviewed in `state/analysis/product-review-2026-10-15/`. Broad categories included applied AI, integrations, backend, web products and mobile. The latest reviewed jobs also asked for GenAI frontends, computer vision and self-hosted video generation. These are directional archive observations, not a representative market survey. FDE is the best career-fit interpretation of the recurring discovery/integration/delivery work, not a measured largest job category.

Eight application categories: forward deployed AI; applied AI/RAG; voice/messaging integration; Python backend/integrations; full-stack AI; computer vision/OCR; generative media pipelines; React Native. Data-science, PHP, AWS and older visual formats remain supplementary links, rather than competing primary headlines.

Public PDFs include contact information. Marketplace PDFs omit direct contact details and use the portfolio evidence link. Both are single-column, text-based, one-page PDFs. Editable Markdown accompanies each public version.

The browser matcher is a local keyword suggestion tool, not an eligibility or qualification assessment. No application is sent. It makes no model/API request and loads no tracking/assistant scripts on the resume page, so pasted job text stays local.
