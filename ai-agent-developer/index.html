Pinterest + Blog Auto Agent (Ready Setup)

Your project now includes an automation endpoint at /api/agents/pinterest-blog that: generates a blog post, generates a cover image, publishes to your blog, and posts the same content on Pinterest.

Required env vars:

  • OPENAI_API_KEY
  • SUPABASE_URL
  • SUPABASE_SERVICE_ROLE_KEY
  • BLOG_IMAGE_BUCKET (public bucket name in Supabase Storage)
  • PINTEREST_ACCESS_TOKEN
  • PINTEREST_BOARD_ID
  • AI_AGENT_TOKEN (custom security token)
  • SITE_URL (example: https://shabeeb.baydot.net)

Manual trigger example:

curl -X POST https://your-domain.com/api/agents/pinterest-blog \
  -H "Content-Type: application/json" \
  -H "x-agent-token: YOUR_AI_AGENT_TOKEN" \
  -d '{"topic":"AI tools for ecommerce","audience":"shop owners","tone":"simple and actionable"}'

A daily cron is configured in vercel.json to trigger this endpoint automatically.

Bulk 15-20 Blogs (With Your Photo)

Use /api/agents/bulk-blog-seed to create up to 20 posts quickly. Default cover image is your photo: /assets/imgs/IMG_7856.JPG. 

curl -X POST https://your-domain.com/api/agents/bulk-blog-seed \
  -H "Content-Type: application/json" \
  -H "x-agent-token: YOUR_AI_AGENT_TOKEN" \
  -d '{"topic":"AI automation for ecommerce","count":20}'

Bulk Pinterest Publish

After posts are created, publish them in bulk using /api/agents/pinterest-bulk-publish.

curl -X POST https://your-domain.com/api/agents/pinterest-bulk-publish \
  -H "Content-Type: application/json" \
  -H "x-agent-token: YOUR_AI_AGENT_TOKEN" \
  -d '{"limit":20}'
