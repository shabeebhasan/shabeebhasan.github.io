Chat and Voice Calling Android App with Sinch and Parse

An Android messenger with phone-number login, one-to-one chat, voice calls through Sinch and push notifications, plus a separate admin app for managing users. Client contract, 2016.

androidjavasinchparsegcmvoice calling

The problem

The client needed a working chat and calling app fast, without building and running their own messaging and VoIP servers.

What I built

  • Phone-number login with the Digits SDK, so there is no password to forget.
  • Chat on Parse, with contacts from the phone, conversation lists and an emoji keyboard.
  • Voice calls through Sinch: an incoming-call screen with answer and decline, and an in-call screen with a timer and end call.
  • Push with GCM, so new messages and calls reach the phone when the app is closed.
  • Admin app: a second Android app listing active and deleted users.

Stack

Android (Java), Parse, Sinch, Digits, GCM, Picasso
